训练

1.  用selective search 选择1000个锚框

2.  为这些锚框分配与其最大的iou的真实框，如果小于iou阈值，就为背景，有n个锚框

3.  计算每个锚框与其分配到的真实框的偏移量

4.  加载ImageNet预训练的VGG16前30层
   
5.  将整张图片导入vgg中，输出卷积层输出的featuremap（c*h*w）

6.  vgg的除了最后全连接层之外的层里面有m个池化层，就锚框的坐标就缩小2的m次方倍，

7. 根据roipooling，对于第一个锚框，在每个通道上，都都划分出7*7的大小，c*7*7，
   
  依此类推，对每个锚框都做相同的操作，划分出n*c*7*7大小的张量

8.  展平，获得n*（c*7*7）大小的二维张量,

9  .导入全连接层，输出n*4096维的张量，

10.  将这个张量导入softmax和线性模型

11.  反向传播训练整个模型（与rcnn不同，会持续更新所有权重）
  
推理

1.	将图片导入vgg除了全连接层之外的层，得到featuremap，
  
2.	将锚框的坐标根据vgg里面的pooling层缩小相应的比例，
  
3.	根据roipooling，划分出n*c*7*7大小的张量
  
4.	展平，获得n*（c*7*7）大小的二维张量,
  
5.	导入全连接层，输出n*4096维的张量
  
6.	将这个张量导入softmax和线性模型
  
7.	获得最大概率的锚框和偏移量进行修正
  
8.	做非极大值抑制（NMS）来去除重复框
